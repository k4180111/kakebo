# Kakeibo — учёт личных финансов

Локальное веб-приложение для ведения бюджета по методу какебо: определить доход и цель накоплений, записывать расходы и регулярно анализировать привычки.

## Технологии

- **React + TypeScript + Vite** — интерфейс и быстрая локальная разработка.
- **IndexedDB** — локальная база данных в браузере, без сервера и регистрации.
- **Web Crypto API** — клиентское шифрование резервных копий AES-256-GCM; ключ выводится из пароля через PBKDF2-SHA-256.
- **Google Drive** — ручное хранение зашифрованных резервных файлов; подключение Google-аккаунта приложению не требуется.

Денежные значения сохраняются целым числом копеек, чтобы избежать ошибок округления. Локальная база доступна только в том браузере и профиле, где приложение использовалось. Зашифрованную копию следует хранить отдельно, а пароль — не забывать: восстановить его невозможно.

Во всех полях ввода сумм тысячные разряды разделяются пробелом, а копейки вводятся через запятую (например, `11 111,11`). Распределение по сферам открывается в режиме просмотра; нажмите «Редактировать», чтобы изменить суммы или проценты, и «Сохранить», чтобы применить изменения.

В плане бюджета для каждого дохода и обязательного расхода выбираются категория, сумма, дата в формате `дд.мм.гггг` и необязательное примечание. Итоги считаются по спискам автоматически; цель накоплений задаётся одним полем. Ранее сохранённые планы с общей суммой дохода или обязательных расходов при чтении превращаются в по одной записи с датой первого числа месяца, поэтому старые суммы не теряются. Прежние названия записей при редактировании сохраняются как примечания.

Бюджет на переменные расходы можно распределить по сферам какебо: для каждой сферы задаётся сумма вручную или процент от доступного бюджета. Процентное распределение пересчитывается при изменении бюджета; общая сумма распределений не может его превышать.

У каждой расходной записи категория и сфера — два независимых признака: категория описывает вид покупки, а сфера — её место в методе какебо. Доходам сфера не назначается. В сохранённых ранее расходах, созданных до появления сфер, историческое значение не угадывается: такие суммы видны отдельно как «Сфера не указана».

Категории расходов, категории доходов и сферы настраиваются отдельными списками. Для сфер задаётся цвет, а для категорий доходов и расходов — независимые иконки из палитры Lucide на 48 значков. Переименование категории обновляет название в уже существующих операциях; переименование сферы сохраняет её идентификатор и привязку операций. Используемые категории и сферы нельзя удалить, пока на них ссылаются операции. Настройки входят в новые резервные копии; старые настройки и копии без цветов и иконок продолжают поддерживаться.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Шифрование резервной копии

В «Настройки» → «Зашифрованная копия» можно создать файл `.enc` или восстановить данные из него. Шифрование выполняется в браузере с AES-256-GCM и отдельной случайной солью для каждой копии. Используйте надёжный пароль длиной не менее 12 символов и храните его отдельно от файла.

## Синхронизация с Google Drive

В «Настройки» → «Зашифрованная копия в Google Drive» можно скачать зашифрованный файл `.enc` и перейти в Google Drive. Загрузите файл в Drive вручную. Для восстановления скачайте `.enc` из Drive и нажмите «Импортировать файл» в приложении. Импорт заменяет текущие данные, поэтому перед подтверждением проверьте выбранный файл.

Google-авторизация и автоматическая синхронизация не используются. Файл шифруется в браузере алгоритмом AES-256-GCM до сохранения; Google Drive хранит только шифротекст. При создании и восстановлении используйте одну и ту же парольную фразу длиной не менее 12 символов и храните её отдельно от файла.
